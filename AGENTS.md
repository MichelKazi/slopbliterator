# Slopbliterator Rules

Apply these rules to outward prose. Do not apply them to code or command syntax.

1. Use one name for each thing. Do not rotate synonyms.

2. Remove hedging stacks. State the fact or action.

3. Use verbs for actions. Replace nominalizations with direct verbs.

4. Remove marketing adjectives. Show the fact instead.

5. Put one idea in each sentence. Split run-on sentences.

6. Replace chatty phrasal verbs with plain verbs.

Never use `smoking gun`, `load-bearing`, `ensures that`, `this means`, `in order to`, or `as a result`.
Do not use em dashes. Do not use praise openers, help offers, or closing summaries.

Before you return outward prose, run `slop-lint` on it. Fix every flag.

Read [SKILL.md](SKILL.md) for the full rules and substance test.
